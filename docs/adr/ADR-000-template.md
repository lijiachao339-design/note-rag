# ADR-000：架构决策记录模板

> 复制本文件为 `docs/adr/ADR-00X-简短标题.md`。
> 每条 ADR 只记录**一个**不可逆或代价高的决策。写 ADR 的成本是 5 分钟，
> 收益是面试时你能立刻答出"当时为什么这么选"——这是资深感的直接来源。

- **编号**：ADR-000
- **日期**：YYYY-MM-DD
- **状态**：提议 / 已采纳 / 已废弃（被 ADR-XXX 取代）
- **相关 commit**：`<sha>`

## 背景

## 决策

选择哪个方案，一句话说清。**必须包含"为什么不是 A"**——只写"选了 B"的 ADR 没有价值。
