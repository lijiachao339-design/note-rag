## Part 1：BM25 倒排索引设计（要出方案，不要写代码）

### 现状与实测数据（都已验证，可直接引用）

`src/note_rag/bm25.py` 目前是**全量扫描**：每来一个查询，就对全部文档算一遍 BM25 分数。

- 语料：1947 篇 markdown（其中 1945 篇进入索引），**17520 个 chunk**，平均每篇笔记 9.01 个 chunk、
  中位数 7、p90 15、最大 83
- 实测 `keyword` 模式 **p95 = 709.2 ms**、p50 = 528.1 ms
- 同一批查询下 `vector` 模式 **p95 = 54.0 ms** —— 瓶颈不在向量检索
- 完整四模式消融（198 查询 × 4 模式 = 792 次检索）耗时 **332 秒**
- 分词：ASCII 词 + 中文 unigram + bigram（`bm25.py:38` 起；`embed.py` 的 hashing 嵌入复用同一 tokenizer）
- 参数：`k1=1.5`、`b=0.75`；`idf` 用 `log(1 + (N - df + 0.5)/(df + 0.5))`
- 现有 API（被 `retriever.py:113-125` 与 `cli.py` 使用，**签名不能破坏**）：
  `BM25()` / `.add(doc_id, text)` / `.extend(pairs)` / `.remove(doc_id)` / `.score(query, doc_id)`
  / `.search(query, limit) -> list[(doc_id, score)]` / `.idf(term)` / `.top_terms(query, limit)` / `len()`
- `retriever.build_keyword_index()` 在启动时把 17520 行从 Postgres 读进来建索引（API 的 lifespan 里调用）

### 硬性约束

1. **重构后分数必须与现在逐位一致。** 这不是"尽量接近"——现有指标
   （`keyword` R@1/5/10/MRR = 0.5758 / 0.7879 / 0.8283 / 0.6650）必须**一位都不变**。
   你可以用 `scripts/exp_hnsw_ef_search.py` 旁边那套离线复现当参照：
   审查 001 里已证明用 `collect_chunks + BM25 + metrics.evaluate` 能逐位复现这四个数。
2. `mypy --strict` 零错误；不引入新依赖（标准库 + 现有依赖）。
3. 排序必须**确定性**：同分时 tie-break 到 doc_id（现在的实现是 `(-score, doc_id)`）。
4. 触达 `bm25.py` 属于 AGENTS.md 的"先测试后实现"范围：请把测试方案写进设计。
5. **本次不要**顺手换成 Postgres 全文检索、不要改分词器、不要改 BM25 参数。

## Part 2：README 与简历叙事定稿（这是给面试官看的东西）

### 背景：审查 001 已经判定，有一句话不能写

审查 001 的第 6 问结论是：**不能**写"hybrid 检索把 recall@5 从 X 提升到 Y"——
在实测数据上 `hybrid` 显著**差于** `keyword`（配对差 +0.2000，按笔记聚簇 bootstrap 95% CI
[0.1333, 0.2667]，不含 0）。原因已在 `docs/experiments/exp-001-baseline-hashing-embedder.md`
里写清楚：hashing 嵌入没有语义，而 RRF 无法拯救一路无效的召回器。

审查 001 同时给出了"**可以诚实写**"的三条，作为你的起点：

> - 自建 198 条标注评测集（180 可回答 + 18 不可回答），实现 pgvector 向量检索、进程内 BM25、
>   RRF 融合三条链路并做四模式消融，四种模式共用同一实现。在离线 hashing 嵌入基线下，
>   BM25 recall@5 = 0.87、hybrid = 0.67 —— 融合一路无效召回器会拉低效果，这是 RRF 的已知行为；
>   据此把"接入真实语义嵌入"定为 P0，而不是先去调融合权重。
> - 评测暴露出 p95 延迟瓶颈在 BM25 的全量扫描（709 ms / 17520 chunk），不在向量检索（54 ms）。
> - reranker 当前是 no-op，消融表如实显示 `hybrid_rerank == hybrid`，不制造虚假提升。
